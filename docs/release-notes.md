# OpenMath judging collection snapshot — October 3, 2026

Four content-addressed material packs are required to restore the complete archive. They contain original submission ZIPs, the indexed catalogue and large datasets/source history. The repository contains the current review book, contestant/problem profiles, score approval tables, explanations, provenance and a complete structure guide.

Use `python tools/restore_materials.py` followed by `python tools/verify_archive.py` from a clone. Every release-backed path is mapped to its exact object and checksum in `publication-manifest.json`. No contestant code is executed by those tools.

70 grouped records / 74 source identities / 80 person-account profiles; 226 contribution notes; 70 problem profiles; 353,195 indexed files. These are not official team or accepted-solution counts. Scores and mathematical assessments remain provisional.

Author permissions confirmed by the user. Third-party authorship/ownership and notices retained. Personal contact details are redacted from loose correspondence. Genuine missing or inaccessible material and excluded UI screenshots are explicitly recorded.
